      Installer EGRADI TV sur iPhone

      Sur l'iPhone, scannez ce code avec l'appareil photo et ouvrez le lien dans Safari, puis suivez ces étapes :

      Ouvrez d'abord cette page dans Safari (l'application à la boussole bleue) :

      1. 1Touchez le bouton Partager en bas de l'écran (ou en haut sur iPad)
      2. 2Faites défiler et touchez « Sur l'écran d'accueil »
      3. 3Touchez « Ajouter » en haut à droite
      4. ✓L'icône EGRADI TV apparaît sur votre écran d'accueil : ouvrez-la comme une application, en plein écran.

      Astuce : une fois installée, l'application peut recevoir les notifications des cultes (iOS 16.4 ou plus récent).

      Installer EGRADI TV sur Android

      📲 Télécharger pour Android

      1. 1Touchez « Télécharger pour Android » ci-dessus.
      2. 2Ouvrez le fichier EGRADI-TV.apk dans la notification ou dans « Téléchargements ».
      3. 3Si le téléphone le demande, touchez « Paramètres » puis autorisez « Installer des applications inconnues ».
      4. 4Touchez « Installer », puis « Ouvrir ».

      Application officielle de l'Église Grâce Divine, signée par EGRADI TV. Les mises à jour arrivent toutes seules.

      Installer EGRADI TV sur votre téléphone

      Scannez ce code avec l'appareil photo de votre iPhone ou de votre Android : la bonne installation s'ouvre toute seule.
      Pas de connexion Internet : les vidéos et le direct reviendront dès que le réseau sera rétabli.
